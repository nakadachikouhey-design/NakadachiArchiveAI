# Project relevance gate

Evidence now passes two independent checks before it can be used as a factual source:

1. Evidence eligibility: excludes generated indexes, AI outputs, temp/work files, previews, code helpers, and derived sidecars.
2. Project relevance: requires the material to identify the target project through its name, aliases, project metadata, path, or sufficiently strong project-context terms.

`KIO_実績マスター.xlsx` is an explicit cross-project exception because it is a curated business master used to substantiate multiple KIO projects.

Materials rejected by either check may still appear under Related Materials / Reference Context, but must not be treated as factual Evidence.
